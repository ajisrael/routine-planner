Setup is now the Plan view

The three bespoke wizard stages (DailyStage / WeeklyStage / MonthlyStage + RoutineRail) are gone. One PlanView renders every surface: the Plan tab unscoped, and each setup stage as the same view filtered to one cadence with pattern-placement semantics. What's left to decide is how much wizard chrome should wrap it - that's what this page proposes. Annotate anything; the decision forms at the bottom queue your picks.

What the conversion did

One component, five scopes

Plan tab = no scope. Setup passes daily / weekly / monthly: the rail filters to that cadence, the calendar opens on the right range, and drops write whole patterns (every day · those weekdays · that date) instead of single occurrences.

Same skills everywhere

Drag from rail, armed tap-to-place, locked context tasks, ghost preview, conflict badge, person chips: learn it once in setup, it's identical in Plan - and vice versa.

Semantics kept per scale

Daily drop re-anchors the routine; weekly adds / swaps / removes weekdays; monthly rail-drop opens that date's day armed. All verified in-browser with real pointer drags.

The open question: how much wizard chrome?

The view under the chrome is now exactly the Plan view. The chrome should answer one thing well: where am I, what's left, and how do I move on - without spending vertical space the calendar needs. Four directions, smallest change first.
